## ⚡ Features

### 🔍 System Analysis

Analyze:

* Windows version
* RAM availability
* CPU information
* Disk space
* Fortnite installation detection
* Crash log detection

---

### ⚡ Quick Fix

Automatically repairs common Fortnite issues by:

* Clearing shader cache
* Clearing Epic Games Launcher cache
* Removing temporary corrupted data

**Recommended for most users.**

---

### 💣 Full Fix (Last Resort)

Advanced recovery mode designed for stubborn crashes.

May:

* Close Fortnite processes
* Close Epic Games Launcher
* Reset Fortnite configuration files
* Clear shader cache
* Reset Epic Games cache
* Repair Easy Anti-Cheat
* Clean temporary files

**Recommended only if Quick Fix does not solve the issue.**

---

### 🛡️ Easy Anti-Cheat Repair

Detects and repairs EAC installation issues.

Useful for:

* Launch failures
* EAC startup errors
* Service issues
* Corrupted EAC installs

---

### 🧠 RAM Diagnostics

Displays:

* Total RAM
* Used RAM
* Available RAM
* Memory pressure level
* Top memory-consuming processes

Helps identify memory-related Fortnite crashes.

---

### 📂 Crash Log Analysis

Analyzes Fortnite crash logs and attempts to identify:

* RAM issues
* GPU problems
* Shader corruption
* Configuration errors

Provides recommendations based on detected patterns.

---

### 💻 System Information

Displays detailed system information including:

* Operating System
* CPU Information
* RAM Statistics
* Disk Usage
* Python Version
* Architecture
