# Contributing to Fortnite Crash Fixer

First off, thanks for taking the time to contribute! 🎉

This project is built by a solo dev who started from zero — so whether you're a beginner or a pro, you're welcome here. Every contribution matters.

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please open an issue with:

- Your Windows version (e.g. Windows 10/11)
- Python version (if running from source)
- Steps to reproduce the crash
- Any logs or error messages (copy-paste them)

Check if the bug already exists before opening a new issue.

### Suggesting Features

Have an idea? Open an issue with the label `enhancement` and explain:

- What problem you're trying to solve
- How the feature should work
- Why it would help others

### Submitting Pull Requests

1. Fork the repo
2. Create a new branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Test your changes locally
5. Submit a pull request

Keep PRs focused and small — it makes reviewing easier.

## Development Setup

### Requirements

- Python 3.8 or higher
- Windows 10 or Windows 11
- VS Code (recommended, but any editor works)

### Running Locally

```bash
git clone https://github.com/Khx2012/fortnite-crash-fixer.git
cd fortnite-crash-fixer
python fortnite_fixer.py
```
### Building the exe locally 
if you don't want to use the exe in releases you could build the exe from your device usin the following command:
```bash
python -m PyInstaller --onefile --windowed fortnite_fixer
```
